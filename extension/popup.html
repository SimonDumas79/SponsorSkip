      The free marker is the default and never leaves this PC. The other two are opt-in and use your own AI plan through Claude Code; "places each edge" sends it only the few lines around each find.

      SponsorSkip reaches your AI through the program on this PC. Today that means Claude, through your own Claude Code sign-in: no API key, nothing billed but your plan.

      1. Install Claude Code, open a terminal and run claude. Sign in with the Claude account whose plan you want SponsorSkip to use.
      2. To see which account is signed in, type /status inside claude. To switch accounts, type /login (or /logout to sign out).
      3. Optional: pick the Claude model by setting SPONSORSKIP_MODEL (haiku, the default, or sonnet) before starting the program.
      4. Restart SponsorSkip: run start-hidden.vbs in the SponsorSkip folder. The line at the top of this popup turns green when it can reach Claude.

      Using a different AI? SponsorSkip only talks to Claude Code today. Adding another means a new reader next to Claude's in server/agents.mjs; the "Let my AI do it" prompt asks your AI to look into it with you.
