      The free marker is the default and never leaves this PC. The other two are opt-in and use your own AI (Manage AI model); "places each edge" sends it only the few lines around each find.

      SponsorSkip asks the AI you already use, through the program on this PC. Pick it here.

      1. Install your AI's command-line tool and sign in once in a terminal: claude for Claude Code, codex for Codex, gemini for Gemini. For Ollama, install it and ollama pull a model. For an API, have its base URL and a key ready.
      2. Pick it above, fill in the model if you want a specific one, press Save, then Test it.
      3. To switch the account your AI uses, do it in that tool (in Claude Code: /status shows the account, /login switches it). SponsorSkip uses whatever it is signed in to.

      Any other AI works too if it has a command that reads a prompt on stdin and prints the answer: choose Custom command.
